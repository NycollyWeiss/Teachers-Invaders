# 🚀 Teachers Invaders

Teachers Invaders é um projeto realizado para a matéria de Física do curso Ciência da Computação. 
Focado na simulação de um lançamento oblíquo de projéteis, permite que o usuário altere parâmetros como Ângulo e Altura do lançamento, Velocidade Inicial e Gravidade enquanto visualiza o resultado de suas escolhas em um programa gráfico.
